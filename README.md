# NRGA-Net: Noise-Residual Guided Attention Network for Satellite Image Forgery Localization

Reproducibility code for the paper *"NRGA-Net: Noise-Residual Guided Attention Network for Local Manipulation Detection and Localization in Satellite Imagery."*

**Quick start for revision tables:**
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/haidarraad-a11y/NRGA-Net/blob/main/notebooks/NRGA-Net_QuickTables.ipynb)

A single script (`src/main.py`) runs the full pipeline: it loads three benchmarks (**Fake-Vaihingen**, **Fake-LoveDA**, and **Fake-LocalDiff**), trains the dual-domain forensic network **once, jointly** across all of them, fine-tunes at higher resolution, evaluates under the **pooled protocol**, calibrates the operating threshold on a **separate calibration split**, and generates all result tables and qualitative figures.

The model produces three outputs from one forward pass:

- a pixel-level **forgery mask** (residual logit cascade + boundary refinement),
- an image-level **Fake / Real decision** (agreement-based detection head),
- a 64-bit **content-bound forensic hash** (CBFH) for provenance verification.

## Datasets (in `data/`)

[![Fake-LocalDiff (Google Drive)](https://img.shields.io/badge/Download-Fake--LocalDiff%20(4.8%20GB)-4285F4?logo=googledrive&logoColor=white)](https://drive.google.com/file/d/1O5l0_hkAosKmHd1HZ55_M8ofMh1MB47m/view?usp=sharing)

| Benchmark | Base imagery | Generator | Train | Test forged | Test authentic |
| --- | --- | --- | --- | --- | --- |
| Fake-Vaihingen | ISPRS Vaihingen aerial | LaMa + RePaint | 2,099 | 386 | 139 |
| Fake-LoveDA | LoveDA land-cover | LaMa + RePaint | 6,852 | 1,292 | 428 |
| **Fake-LocalDiff (ours)** | PRDLC-PRO + RRSIS scenes | Latent diffusion (SD-2 inpainting) | 8,000 | 800 | 800 |

Fake-Vaihingen and Fake-LoveDA are released by the FLDCF authors (Sui et al., TGRS 2024). Fake-LocalDiff is the benchmark introduced in our paper (prompt-driven latent-diffusion local replacements with byte-exact compositing) — **[download Fake-LocalDiff.zip (4.8 GB)](https://drive.google.com/file/d/1O5l0_hkAosKmHd1HZ55_M8ofMh1MB47m/view?usp=sharing)** and extract it as `Local_Diffusion/` under your dataset root. The authentic folders of each benchmark are shared between its two generator variants and are de-duplicated at load time (`cfg.DEDUPE_REALS`).

Expected folder layout under the dataset root (see `data/README.md`):

```
DATA_ROOT/
├── Fake-Vaihingen/{real,fake}/{train,val}/...
├── Fake-LoveDA/{real,fake}/{train,val}/...
└── Local_Diffusion/{real,fake,mask}/{train,val}/...
```

## Reproducibility checklist for the revised submission

- **Immutable train / calibration / test split**: generated by `scripts/create_splits.py` using `seed=42`; saved as `splits/train_full.csv`, `splits/calibration.csv`, `splits/test.csv`, and `splits/leave_one_family_out/*.csv`. The final-test split is never used for temperature, threshold, uncertainty-bound, or checkpoint selection.
- **Corrected metrics**: `src/metrics.py` enforces forged-class `Dice = F1` and the mutual consistency of pooled `precision/recall/F1/IoU`.
- **Fast table generation**: `notebooks/NRGA-Net_QuickTables.ipynb` trains on a 2,000-image subset and emits Tables 3–9 as CSV files in `results/quick_tables/`.
- **Full pipeline**: `src/main.py` reproduces the final submission numbers when run on the complete dataset using the generated splits.
- **Released artifacts** (to be uploaded after full-run recomputation): trained checkpoints, per-image predictions, and the CSV metrics used for every table.

## How to run

```
pip install -r requirements.txt
set NRGA_DATA_ROOT=D:\path\to\DATA_ROOT     :: Windows (export on Linux/Colab)
python scripts/create_splits.py --root %NRGA_DATA_ROOT% --seed 42
python src/main.py
```

Checkpoints and CSV reports are written to `$NRGA_DATA_ROOT/NRGA-Net/`.

### Colab / Jupyter

The script also runs top-to-bottom in a notebook. Mount Drive, set `NRGA_DATA_ROOT` (or edit `BASE_DB` near the top of `src/main.py`), then:

```
%run src/main.py
```

For a fast, self-contained reproduction of all result tables, open the Colab notebook above.

## Notes

- Training used a single NVIDIA RTX PRO 6000 (102 GB); the 256px stage runs with batch 8 and bf16 autocast. Lower `Config.BATCH_SIZE` and disable `DILATE_STAGE4` on smaller GPUs.
- `RESUME = True` resumes from the rolling `last` checkpoint after a dropped session; a health-check section refuses to evaluate a NaN-poisoned checkpoint.
- The CBFH provenance arm is integrated but its contrastive loss is off in the localization run (`LAMBDA_PROV = 0.0`); set it back to 0.5 to train the provenance objective.
- Random seeds are fixed for reproducibility.
